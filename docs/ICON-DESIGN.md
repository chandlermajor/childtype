# 图标设计规范 / Icon Design Specification

本文档定义 ChildType 扩展图标的尺寸、设计要求和技术规范。

---

## 尺寸要求

Chrome Web Store 要求提供以下三种尺寸的 PNG 图标：

| 尺寸 | 像素 | 用途 | 格式 |
|------|------|------|------|
| 16×16 | 16px × 16px | 浏览器工具栏图标 | PNG |
| 48×48 | 48px × 48px | Chrome Web Store 列表展示 | PNG |
| 128×128 | 128px × 128px | Chrome Web Store 详情页、安装对话框 | PNG |

**注意：**
- 必须使用 PNG 格式，不支持 SVG（打包后不可用）
- 背景必须为透明
- 推荐使用有圆角的方形设计

---

## 设计概念

### 主题
可爱、友好的儿童键盘图标，传达「学习打字」的核心功能。

### 核心元素
1. **键盘主体** — 简化的 QWERTY 键盘形状，圆角按键
2. **彩色按键** — 3-4 个按键使用不同颜色（代表指法分区概念）
3. **儿童友好风格** — 圆润的边角，明亮的色彩

### 色彩方案

| 角色 | 颜色 | 色值 | 用途 |
|------|------|------|------|
| 键盘底色 | 柔和蓝 | `#6C5CE7` | 键盘主体背景 |
| 按键 1 | 珊瑚红 | `#FF7675` | 左小指/右小指区域 |
| 按键 2 | 金色 | `#FDCB6E` | 左中指/右中指区域 |
| 按键 3 | 薄荷绿 | `#55E6C1` | 左食指/右食指区域 |
| 按键 4 | 淡紫 | `#A29BFE` | 基准键位高亮 |
| 描边/细节 | 白色 | `#FFFFFF` | 按键轮廓、文字 |

### 16px 版本

由于尺寸极小，需要高度简化：
- 只保留键盘外轮廓和 2-3 个彩色点
- 避免文字
- 确保在小尺寸下仍可辨识

### 48px 版本

- 完整的简化键盘（2-3 行按键）
- 4 个彩色按键清晰可见
- 可选添加文字 "CT" 或 "ChildType"

### 128px 版本

- 最详细的版本
- 完整的 QWERTY 键盘布局（3 行）
- 彩色按键标注指法分区
- 可选添加标题文字

## 设计规范

### 圆角
- 所有按键使用圆角矩形，半径 = 按键宽度的 15-20%
- 键盘外框圆角半径 = 整体宽度的 8-10%

### 间距
- 按键之间间距 = 按键宽度的 5-8%
- 行间距 = 按键高度的 10-15%

### 对比度
- 彩色按键与底色之间对比度至少 3:1
- 白色文字/描边在彩色背景上清晰可读

### 可辨识度测试
- 16px: 在白色背景上 1 秒内可辨识为「键盘」
- 48px: 可看到按键颜色和排列
- 128px: 可辨认指法分区概念

## 制作工具建议

| 工具 | 适用阶段 | 说明 |
|------|----------|------|
| Figma | 设计阶段 | 免费，支持多画板，导出多尺寸 |
| Adobe Illustrator | 设计阶段 | 专业矢量设计，导出 PNG |
| Canva | 快速原型 | 在线工具，模板丰富 |
| InkScape | 开源替代 | 免费矢量编辑器 |

### Figma 导出步骤

1. 创建 3 个画板（16×16, 48×48, 128×128）
2. 使用相同的设计元素，按尺寸缩放
3. 导出为 PNG，取消「导出时包含画板名称」
4. 文件名：`icon-16.png`, `icon-48.png`, `icon-128.png`

## 文件放置

```
childtype/
└── icons/
    ├── icon-16.png    (16×16, ≤ 4KB)
    ├── icon-48.png    (48×48, ≤ 16KB)
    └── icon-128.png   (128×128, ≤ 50KB)
```

**文件优化：**
- 使用 PNG 压缩工具（如 TinyPNG）减小文件体积
- 目标总图标体积 < 100KB
- 透明背景，无 Alpha 通道浪费

## 审核注意事项

Chrome Web Store 图标审核标准：
1. ✅ 图标必须反映扩展的实际功能（打字/键盘）
2. ✅ 不得使用其他扩展的图标或商标
3. ✅ 图标必须清晰、专业、无模糊
4. ✅ 不得包含误导性元素（如「免费」「官方」文字）
5. ✅ 建议提供 48px 和 128px 两个尺寸（至少一个）
